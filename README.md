# ✈️ TravelToday – Travel Agency Website

TravelToday is a modern and responsive travel agency web application designed to showcase travel destinations, services, and provide an engaging user experience for exploring trips and offers.

---

## 🌍 Overview

This is a full-stack travel agency platform that allows users to browse destinations, book reservations, and create accounts with authentication features for both users and administrators. It also includes an admin dashboard with statistics and full CRUD management of destinations, users, reservations, and contact messages, providing complete control over the platform’s operations.

---

## 🛠️ Tech Stack

- HTML5  
- CSS3  
- JavaScript  
- PHP  
- MySQL  

---

## ✨ Features

### 👤 User Side
- 🏝️ Browse travel destinations and available packages
- 📄 View detailed information about each destination
- 🧾 Make and manage reservations
- 🔐 User registration and authentication system
- 👤 Secure login/logout functionality
- 💬 Contact the agency through a contact form

---

### 🛠️ Admin Side
- 📊 Dedicated admin dashboard with statistics overview
- ➕ Full CRUD management for destinations (Create, Read, Update, Delete)
- 👥 Manage registered users
- 📅 Manage and track reservations
- 📩 View and manage contact messages
- 🔐 Secure admin authentication system
